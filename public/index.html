What the agent actually does

  1. Resolves taste into entities. An artist, a film, a brand, a book — Qloo turns each into a real entity with an ID.
  2. Ranks the same places once per person. Never once for the group. Averaging people together is the failure this exists to fix.
  3. Tests the group score. A place has to win for everybody. The group score is a harmonic mean, so one indifferent person drags it to zero — a place nobody objects to cannot beat a place everybody likes.
  4. Revises when the answer is nothing. If no place clears everyone, the agent loosens a constraint, asks Qloo again, and tells you exactly what it gave up.
  5. Shows its receipts. Every score, every tag, every call — including the cached ones.
