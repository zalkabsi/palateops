Every recommender answers “what do you want”. Duet answers the harder question: given two specific people, which places actually work for both — and where are you only pretending to agree?

How the answer is made

  1. Each taste becomes a Qloo signal. An artist, a film, a brand, a book — Qloo resolves each to a real entity.
  2. Qloo ranks the same real places twice. Once for each person, in the same city. Never a blended average of the two.
  3. Duet joins the two rankings. A place has to win twice to be called a shared choice. The joint score is a harmonic mean, so a place one of you merely tolerates cannot beat a place you both like.
  4. You see the evidence. Both scores, the tags behind them, and the exact calls that produced them.
